# kaeidos-test-app

A tiny web app that greets a person by name. KAEIDOS, an AI software factory, changes it to
prove its work end to end. It has no dependency but Node 24.

```bash
npm ci        # nothing to install, but it checks the lockfile
npm test      # the tests
npm start     # the app on http://localhost:3000, then try /?name=Ada
```
